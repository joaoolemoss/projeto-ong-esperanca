## Recomendações Técnicas

### Formatos Recomendados:
- JPG/JPEG: Para fotografias e imagens com muitas cores
- PNG: Para logos e imagens com transparência
- WebP: Para melhor performance (com fallback)

### Dimensões Sugeridas:
- Banners principais: 1920x600px
- Imagens de conteúdo: 800x600px
- Thumbnails: 400x300px
- Logos de parceiros: 200x100px

### Otimização:
- Comprimir todas as imagens (máximo 200KB por imagem)
- Usar lazy loading para imagens fora da viewport inicial
- Implementar srcset para imagens responsivas
- Adicionar alt text descritivo em todas as imagens

### Acessibilidade:
- Todas as imagens devem ter atributo alt descritivo
- Imagens decorativas devem ter alt vazio (alt="")
- Usar figure e figcaption quando apropriado
- Garantir contraste adequado em imagens com texto

## Observações
Este é um projeto educacional. Em produção, todas as imagens placeholder devem ser substituídas por imagens reais, respeitando direitos autorais e autorizações de uso de imagem.
